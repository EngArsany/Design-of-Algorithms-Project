### Spring 2026 · Ain Shams University · Faculty of Engineering

## 📋 Overview

This repository contains the C++ source code for the **CSE245 group project**, covering ten classical algorithmic problems. Each problem is solved using one or more algorithm design paradigms, including **Divide & Conquer**, **Dynamic Programming**, **Greedy**, **Brute Force**, and **Iterative Improvement**.

---
## 🧩 Tasks Summary

| # | Problem | Techniques Used |
|---|---------|----------------|
| 1 | **Tromino Tiling** — Tile a 2ⁿ×2ⁿ board (one missing square) with 3-colored L-shaped trominoes so no adjacent trominoes share a color | Divide & Conquer, Brute Force |
| 2 | **Knight's Tour** — Find a closed knight's tour on an n×n chessboard; determine valid board sizes and minimum moves | Greedy |
| 3 | **Tower of Hanoi (4 Pegs)** — Transfer 8 disks across 4 pegs optimally; verify/achieve 33-move solution | Divide & Conquer, Dynamic Programming |
| 4 | **Knight Swap (3×4 Board)** — Exchange positions of 3 white and 3 black knights in minimum moves | Iterative Improvement |
| 5 | **Shooter & Moving Target** — Guarantee hitting a moving target across n hiding spots | Divide & Conquer |
| 6 | **Point Lattice Crossing** — Cross all points of an n×n lattice using exactly 2n−2 straight lines | Dynamic Programming |
| 7 | **Job Scheduling** — Schedule jobs on one machine to minimize total lateness penalty | Dynamic Programming, Brute Force, Divide & Conquer |
| 8 | **Minimum Graph Cut** — Find approximate minimum cut in a weighted graph | Iterative Improvement, Brute Force |
| 9 | **K-Clustering** — Partition n points into k clusters optimally | Iterative Improvement, Divide & Conquer, Brute Force |
| 10 | **Coin Removal Puzzle** — Remove all coins from a line by removing head-up coins and flipping neighbors | — |
